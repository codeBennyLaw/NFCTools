# 0.1.1

- 修复单次写入成功后，待写入列表与导入备份仍然残留的问题。完成回读校验后清空已写入草稿及录入框，并同步清除本地保存的内容，重启后不再恢复旧列表。
- 写入失败、取消等待或切后台时保留草稿，方便重试；连续写卡仍保留内容，用于下一张卡。
- 写入期间通过分享或导入收到的新内容会保留；读卡结果、卡包和历史记录不受清理影响。
- 版本号更新为 0.1.1（versionCode 11），安装包命名为 `NFCTools-debug-v-0-1-1.apk`。
- 首次接入 GitHub 仓库，发布 `NFCTools-release-v-0-1-1.apk`；Release 与已有 Debug 包使用相同签名，可直接覆盖安装。后续提交、PR 和 Release 使用统一中文格式。

# 0.1.0

- 写入流程改为“选类型 → 填写或选择 → 贴卡写入”；移除普通写入的额外确认弹窗，擦除和永久只读仍需确认。
- 首页状态区缩小，常用操作直接可见；写入按钮固定在底部，键盘打开时避让。
- 打开 App 标签：从已安装且可启动的应用中选择，写入标准 Android Application Record。
- 通讯录选择；粘贴识别网址、电话、邮箱、位置、vCard 和 Wi-Fi 二维码文字；网址自动补全 HTTPS。
- 系统分享导入文字、链接和小文件；原始 .ndef 备份可以转为可编辑内容，未知记录保留原样复制路径。
- 读卡后直接编辑、保存到卡包或准备复制到下一张卡；保留原始 MIME 文件内容。
- 最多 100 张本机卡包，改名、分类、删除；从当前卡、卡包或最近记录选择两张进行比较。
- MIFARE Classic 单个已知 Key A / Key B 的扇区读取；Ultralight 页读取；Dump 导入导出与比较。
- 连续写多张标签，显示完成数量；待写入内容在开始时固定，切后台和取消会停止。
- 未点“添加”的录入内容也自动保存；切页、旋转和重启后可继续填写。
- 读取失败保留错误说明；部分 NDEF 内容不可读时仍展示 UID、协议等公开信息；增加正反序十进制 UID。
- 升级 compile / target SDK 到 37、AGP 9.1.1、Gradle 9.4.1、Kotlin 2.2.10，配置 Android 17 独立 NFC 分发权限。
- NFC 设置、设备检测和荣耀系统钱包入口；未执行的贴卡操作取消时不影响草稿。

参考了用户提供的[“手机门禁卡NFC”商店页](https://appmarket-h5.cloud.honor.com/h5/share/latest/index.html?shareId=2114642888767442944&shareTo=wechat)中的卡包、比较和内存工具分类，并保留本项目的原生 Material 界面。

MagicOS 11 的代码层适配已加入。当前无荣耀真机；不能将模拟器与静态检查结果视为 MagicOS 11 实卡验证。门禁模拟、钱包开卡、支付与交通卡业务仍由系统和发卡方支持决定。
